# 内容安全与史料来源分层政策

## 三层来源

- **史实层**：正史、裴注及可核验历史地理；界面标“史实/正史来源”。
- **文学层**：《三国演义》、民间传说和后世形象；界面标“演义/传说”，不得伪装成史实。
- **原创层**：本项目数值、对白、事件分支和程序化表现；不得声称来自原作或古籍。

## 敏感内容规则

1. 系统分类和现代旁白使用中性族群/地域名称；有研究价值的时代词只在引用或叙事语境中
   保留，并紧邻标注来源和时代局限。
2. 玩家可执行婚配要求双方在当前年份均满18岁；历史资料记载不绕过该门槛。
3. 具名人物不得作为库存、赠品、忠诚消耗品或可转移奖励。宫廷人脉是非人格化资源。
4. 战争、死亡、俘虏、疾病、间谍、赌博等内容在剧本入口提供内容提示；不美化现实暴力、
   人口贩运或针对现实群体的歧视。
5. 每条人物/事件数据保留 `history`、`annotation`、`romance`、`folklore` 或 `original`
   来源分类；无法分类的内容不得作为“史实”展示。

## 人工复核词表

以下词出现时必须人工判断是否属于有来源引用，而不能仅做机械禁词：蛮、胡、羌、夷、奴、
献美、后宫、买卖、屠城、瘟疫。生产 UI 和系统字段默认不得使用人格物化措辞。
