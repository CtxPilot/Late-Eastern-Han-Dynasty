## 一、立项背景与设计动机

在 Session 476 中，本游戏成功构建了东汉十三州 106 郡国、三十诸侯全割据的宏大开局，并在 Session 477 全量深化了朝廷中央与地方州牧刺史官制体系。然而，在现有外交子系统中，仍存在显著的扁平化与割裂现象：
1. **外交行动极度匮乏**：当前仅实装了基础的「进贡」与「缔结同盟」，完全缺失东汉末年合纵连横不可或缺的**「宣战」**、**「停战停火协议」**、**「附庸称臣从属」**与**「朝贡缴纳」**；
2. **缺乏多方盟约与会盟机制**：以 190 年「关东反董联军」为代表的多方会盟，此前仅能以点对点的双边同盟生硬表达，缺乏统一的联盟实体（`Coalition`）、盟主地位（`leaderFactionId`）、共同作战目标（`targetFactionId`）与盟约期限管理；
3. **从属与朝贡机制未闭环**：弱小割据诸侯（如白波军杨奉、张杨、韩遂或降伏者）缺乏成为大国附庸的生存路径；宗主国缺乏收取岁贡与保护附庸的政治利益；
4. **天子诏命与天下大势未激活**：占领洛阳或长安迎奉天子的势力（`controlsEmperor`），无法以天子名义向各路诸侯颁发**「讨逆诏」**、**「册封州牧」**或**「征辟朝贡」**，未能体现「挟天子以令诸侯」的战略威慑力。

本提案旨在通过严格的向下兼容与确定性设计，全面激活多方盟约、从属朝贡、宣战停火与天子诏命体系，形成深刻的外交博弈与地缘政治闭环。

## 二、核心架构与系统机制

### 1. 宣战（`declareWar`）与停火协议（`proposeTruce`）

#### 1.1 宣战逻辑与背信惩罚
- **主动宣战**：玩家或 AI 势力可向指定非同盟势力宣战，双方关系立即切换为 `DipRelation.WAR`，友好度设为 `-80`；
- **背信弃义判定（`betrayal`）**：
  - 若在**同盟有效期内**或**停战协议期内（`truceMonths > 0`）**单方面主动宣战，触发背信惩罚；
  - 惩罚：发起方声望扣减 50 点（`fame - 50`），全军及全国城池士气扣减 10 点，清空友好度至 `-100`；
  - 记录文言起居注：「XX 背弃盟约，悍然兴兵，天下皆鄙其不义，声望大损！」；
- **从属国联动**：对附庸国宣战视同对宗主国宣战，宗主国自动参战。

#### 1.2 停火协议（`proposeTruce`）与期限递减
- **条件与消耗**：处于 `WAR` 或 `HOSTILE` 状态，消耗 500 金谈判诚意金；
- **协商成功率**：
  - 基准 40% + 使者魅力加成（`envoy.stats.charisma * 0.3%`）；
  - 军力修正：若我方军力大于对方 1.5 倍，成功率 +20%；若对方陷入多线作战（同时与 ≥2 个势力开战），成功率 +25%；
  - 友好度修正：`favorability * 0.2%`；
- **停火达成**：
  - 双方关系转为 `DipRelation.NEUTRAL`，`favorability` 恢复至 0；
  - 设置停火保护期：`DiplomacyLink.truceMonths = months`（默认 12 个月）；
  - 在 `truceMonths > 0` 期间，双方 AI 禁止发起军事出征；玩家若强行宣战则触发上述背信惩罚；
  - 每月月结 `turn.ts` 时，全图 `truceMonths > 0` 的连接自动减 1。

### 2. 称臣从属与岁首朝贡体系（Vassalage & Tribute）

#### 2.1 确立从属关系（`demandVassal` / `submitVassal`）
- **从属判定条件**：
  - 宗主方综合国力（城池数 ≥ 2 倍且兵力 ≥ 3 倍）压倒从属方，或从属方仅余 1 城且濒临覆灭；
  - 双方非极度敌对（`favorability >= -20`）；
- **从属状态契约**：
  - `targetFaction.overlordFactionId = overlordId`；
  - `overlordFaction.vassalFactionIds` 包含 `targetId`；
  - 双方关系固化为 `DipRelation.ALLIED`，友好度上升至 50；
  - 宗主国声望提升 +30；
  - 从属国丧失独立对外宣战权，与宗主国外交敌人自动保持同步。

#### 2.2 岁首朝贡结算（`turn.ts` 每年 1 月）
- 每年 1 月月结，从属国计算上年度税赋总入账，向宗主国上缴 **15% 金钱** 与 **15% 粮食**（若国库不足则按现有全部结余的 15% 扣缴）；
- 宗主国国库相应增加，起居注记录：「岁首纳贡：从属诸侯 XX 向宗主国进献金 XX、粮 XX」；
- 若宗主国处于欠俸危机，朝贡金直接优先补益宗主国俸禄池。

#### 2.3 解放从属（`releaseVassal`）
- 宗主国可主动宽宥解放从属国，归还其完全独立主权；
- 解放后双方友好度提升至 80，宗主国声望提升 +15。

### 3. 多方会盟实体（`Coalition`）与盟主统领

#### 3.1 会盟数据契约
```ts
export interface Coalition {
  id: string; // 唯一标识，如 "coalition_anti_dong"
  name: string; // 联盟中文名称，如 "关东反董联军"
  leaderFactionId: number; // 盟主势力 ID（如 袁绍 2）
  targetFactionId: number; // 共同声讨目标（如 董卓 1）
  memberFactionIds: number[]; // 会盟诸侯 ID 列表
  startYear: number;
  startMonth: number;
  durationMonths: number; // 盟约预设有效期（如 24 个月）
  remainingMonths: number; // 剩余月数
}
```

#### 3.2 盟主特权与共同作战（`jointWar`）
- **同盟互保**：联盟所有成员之间自动维持非战友爱，不得内部开战；对目标敌对势力自动保持战争；
- **号召共同作战**：盟主可向盟友发起「共同作战」动员令，联盟成员在下一季度军事决策中对目标敌军的进攻倾向提升 3 倍；
- **自然解散与胜利**：
  - 若目标势力覆灭（`isAlive = false`），联盟达成大捷，所有参盟诸侯声望 +40，联盟圆满解散；
  - 若盟约到期（`remainingMonths <= 0`），联盟和平解散，诸侯恢复自由外交。

### 4. 挟天子以令诸侯：天子诏命系统（Imperial Decrees）

当某势力占领汉帝所在城池（`controlsEmperor(state, factionId) === true`）时，解锁天子诏命特权，可借朝廷天威号令海内：

| 诏命类型 | 效果与消耗 | 战略影响 |
|---|---|---|
| **讨逆明诏** (`denounce_traitor`) | 耗皇权 20 点（诸侯无皇权耗金 500）；指名宣判目标势力为国贼叛逆 | 目标势力天命 -10、人心 -10；全天下尊汉势力对其友好 -20，发起方获合法讨伐理由且宣战不扣声望 |
| **锡命册封** (`appoint_governor`) | 耗金 300；正式册封指定诸侯为所辖州州牧/刺史 | 目标诸侯声望 +25，对朝廷掌控势力友好 +30，确立合法地方统帅名义 |
| **天下征贡** (`summon_tribute`) | 耗金 200；诏命天下诸侯向朝廷岁首进献金粮 | 尊汉或顺从诸侯应诏进呈贡赋（宗主金+200/粮+500），抗诏诸侯天命 -5 |
