# Agent 与测试数据留存和脱敏政策

## 适用范围

本政策覆盖 Agent 对话、提示词、回答、工具输出、文件快照、浏览器页面快照、调试日志、
会话标识及包含这些内容的数据库/WAL/备份。

## 强制规则

1. Agent 和浏览器工具状态必须位于仓库外的用户私有数据目录；工具暂时强制写入仓库时，
   目录权限必须为 `0700`、文件为 `0600`，并由根 `.gitignore` 明确排除。
2. 默认日志不得保存访问令牌、Cookie、Authorization、完整请求正文、思维草稿或完整源码快照。
3. 活跃调试日志保留不超过 30 天；经项目所有者明确标记的审计证据最多保留 90 天。
   到期后删除数据库、WAL、SHM、日志、快照及备份副本。
4. 导出给第三方前必须替换用户目录、邮箱、IP、会话 ID，并执行秘密/PII 扫描。
5. 禁止把 `.crush/`、`.playwright-mcp/`、`.omo/`、`.opencode/`、`.zcode/`、
   `.codegraph/`、`agent-exports/` 或 `audit-evidence/` 加入 Git 或发行包。
6. 平台侧未导出的会话不能声称已经审查；导出复审必须记录平台、时间范围、会话数、
   导出文件 SHA-256、缺失项和删除结果。

## 清除演练

每次公开发布前，以测试会话执行：创建 → 导出脱敏 → 删除活跃文件 → 删除 WAL/备份 →
全盘文件名和内容复扫。只在五步均有可复核结果时判定通过。
