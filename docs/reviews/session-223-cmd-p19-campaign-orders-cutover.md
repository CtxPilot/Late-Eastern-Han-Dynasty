# Session 223 · CMD-P19 Campaign 军令迁移审查

## 结论

Campaign Army 的强攻、劝降、撤退、营建与参谋行动已统一迁入命令坞
`军事 → 军令`。左栏战役保留军团详情与战报读取，但所有状态变更按钮物理删除，因此玩家军令
只有一个生产入口。既有 `campaign*` store/API/引擎继续作为权威链路，无 Schema、数值或存档变化。

## 终审与复验

- 强攻、劝降、撤退沿用统一终审，并按最新军团归属与阶段复验。
- 8 种营建设施首次接入统一终审；终审展示金耗与工期，提交前复验阶段、在建状态与势力金。
- 激励、陷阱、休整、斥候首次接入统一终审；提交前复验参谋存在、智力与体力门槛。
- 取消终审不调用 API、不改变权威状态；行军不新增独立 UI，仍由既有回合推进负责。
