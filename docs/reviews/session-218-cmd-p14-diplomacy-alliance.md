> 范围：S20 / S08。命令坞外交“盟约”分面接入当前唯一已实装条约——结盟；
> 旧外交仍保留至下一阶段原子切换。

## 一、交付

- “盟约”分面启用结盟，沿用“势力”目标选择，不创建第二份目标草稿。
- 列表层显示关系、友好、己方总金、shared `calculateAllianceChance()` 的当前成功率、
  权威候选使者及魅力。
- 战争、已同盟、友好 `<30`、总金 `<500` 均禁用并显示具体原因。
- 终审显示目标、金500、成功率、成功/失败后果；取消不消费金或 RNG。
- 确认前按最新快照复验目标存活、关系、友好和金钱；提交继续调用既有
  `formAlliance()` → `/diplomacy/alliance` → 权威 RNG 引擎。
- 停战、互不侵犯、求援、借道等未实装条约只作文字说明，无假按钮；点化仍无外交入口。

## 二、验证

`pnpm verify-cmd-p14-headless` 在 1440×900 英雄集结曹操局：

- 初始友好 −30 时结盟禁用并显示门槛；
- 完全通过新进贡入口执行4次，使友好达到30；
- 结盟终审取消后权威快照不变；
- 确认后总金 −500、日志为 `alliance` 且含成功率，本次固定运行结果为成功→`allied`；
- 战争目标结盟禁用；未实装条约/点化按钮为0；console error=0。

固定成功/失败 seed、概率单调、上下界及失败关系不变继续由 `verify-negotiation-r2` 40/40 覆盖。
