# Session 231：CMD-P27 计略三分面只读态势

> 范围：S20 / S17 计略命令抽屉只读层。本轮不迁移四计写链，不删除旧 `PlotPanel`，
> 不改变 API、引擎、规则、数值、RNG、Schema 或存档。

## 一、交付

命令坞“计略”从 legacy 说明升级为可用抽屉，固定三个分面：

- **态势**：进行中数量/上限、势力总金、美女库存、detailed 敌城、空闲女间谍、
  空城疑兵候选；明确总军师任免仍归朝廷。
- **发起**：只读列出四计成本与前置，明确探秘/女间谍归情报域；没有提交按钮。
- **进行中**：仅展示玩家发起的计谋、目标、准备/生效/结算阶段、剩余月份、暴露与结果。

`buildStrategyOverview(game)` 直接从当前 `GameState` 派生，不新增客户端业务缓存，也不聚合
敌方计谋。进行中上限按当前服务端规则展示为4；真正门禁仍由 S17 引擎最终裁决。

## 二、迁移边界

- 左栏 `PlotPanel` 仍是美人计、离间计、假情报、空城疑兵唯一玩家提交入口。
- CMD-P27 抽屉内 `data-command-write="true"` 数量必须保持0。
- detailed 情报只列当前 S06 允许玩家看到的报告，不从服务端隐藏状态反推。
- 中止、反制、总军师献策尚无完整权威规则，不提供假按钮。

## 三、验证

新增 `pnpm verify-cmd-p27-headless`，在 1440×900 英雄集结曹操局实测：

- `态势｜发起｜进行中` 三分面各唯一，初始进行中显示 `0/4`；
- 旧 `btn-plot-launch` 保持1，新计略提交入口为0；
- 从旧入口对刘备军发起离间计后，新“进行中”即时出现
  `sowDiscord / prep`、目标刘备军与“准备中”；
- 控制台 error 为0。

客户端模型测试覆盖敌我计谋过滤、资源汇总、探秘敌城、空闲女间谍和空城候选。
