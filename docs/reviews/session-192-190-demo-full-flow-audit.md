# Session 192：190《关东义兵》完整展示性流程排查

> 范围：选剧本 → 城市信息/内政 → 人事 → 出征/战斗 → 外交 → 谍报/计谋 → 连续回合 → 朝廷门禁。  
> 方法：1440×900 Headless Chrome，从开卷页开始实际点击；选用一城、两将、资源较紧的
> **孙坚鲁阳军**。页面状态与 `/api/game/state` 只读快照交叉核对。  
> 结论性质：本轮只排查、截图和定位，不修改任何代码。

## 一、结论

**190 剧本的非军事展示流程基本可走，但“出征 → 同节点友军 → 野战结算”存在阻塞性状态破坏，
当前不宜把完整 Demo 流程判为健壮。**

本次实际走到 190 年 4 月（完成 3 次结束回合）后，确认：

- 选剧本、城市三类信息、五项内政、人事搜索、两名武将四页签、进贡、密探招募与任务、
  离间计、历史事件选择均可完成；
- 正常数值未出现负数或异常暴涨；
- 孙坚军抵达洛阳时与开局盟友曹操军发生野战，盟友被当作敌军；
- 野战防守方残军回写时复制了同一支孙坚军，产生相同 Army ID、React 重复 key 控制台错误，
  下一回合继续复制；
- 玩家军虽显示在敌城“驻守”，洛阳仍属董卓，流程不再进入正常围城/占城闭环。

问题统计：**阻塞性 2 项、明显异常 4 项、体验瑕疵 3 项**。

## 三、问题清单

### 阻塞性 B-1：战役层把盟军视为敌军并强制野战

**复现**

1. 190 剧本选孙坚（初始与曹操 `relation: allied`）。
2. 孙坚军自宛出征洛阳。
3. 推进至 190 年 3 月，让 AI 曹操军也抵达洛阳。
4. 日志出现“曹操军 在 洛阳 与 孙坚军 遭遇，进入野战”。
5. 强攻后报告为“曹操军 · 自动结算”，孙坚与曹操发生单挑。

**影响**

- 关东盟军在核心讨董展示路径中互相攻击；
- 外交关系对战役同节点判定失效；
- 玩家无法可靠与盟军共同进攻同一目标。

**定位**

- `server/src/engine/campaign.ts:435`：`enemyArmy` 仅检查 `factionId !==`，未检查外交关系；
- `server/src/engine/campaign.ts:898` 附近：强攻查找同节点敌军同样只比较势力 ID；
- 对照当时权威状态，孙坚/曹操外交仍为 `allied`，不是显示缓存问题。

**证据**

- `27-after-turn-2.png`
- `28-allied-armies-battle.png`
- `30-assault-result.png`

### 阻塞性 B-2：野战残军回写复制 Army，导致同 ID 状态持续增殖

**复现**

沿 B-1 继续：

1. 190 年 3 月首次展开战役时，“我军(2)”出现两支同名孙坚军；
2. `/api/game/state` 中两项均为 `id=army-114-190-1-1`，兵力分别 3000 与 2573；
3. 控制台报 React “two children with the same key”；
4. 强攻后暂时剩 1 支；再推进一回合又变成两支同 ID 军队（2573/2207）。

**影响**

- 权威 `campaignArmies` 违反 ID 唯一性；
- 每次同节点野战都可能继续复制军队、兵力和武将占用状态；
- React 列表身份失效，卡片可能重复、遗漏或绑定错误；
- 玩家军被置为洛阳“驻守”且可建设施，但洛阳仍属董卓，正常围城/占领流程中断。

**定位**

- `server/src/engine/campaign.ts:966`：战斗结算初始数组只过滤攻方 `army.id`；
- `server/src/engine/campaign.ts:1000-1007`：敌军残部被再次 `push`，但原敌军未先从数组移除；
- `client/src/components/campaign/CampaignPanel.tsx:72-75`：前端直接渲染全部己方 Army，重复 ID 因而触发 key 错误。

**证据**

- `28-allied-armies-battle.png`
- `30-assault-result.png`
- `31-after-turn-3.png`

### 明显异常 A-1：君主简册的势力总金/总粮使用陈旧聚合值

**复现**

五项内政和一次人事搜索后，顶栏/城市显示金 1820、粮 3150；打开孙坚简册，仍显示开局
总金 2280、总粮 3300。

**影响**

同一屏幕存在两套势力资源数，玩家无法判断余额；直到回合资源同步前持续错误。

**定位**

- `client/src/components/officer/OfficerDetail.tsx:111-122`：总金/总粮直接读取 `faction.gold/food`；
- 日常操作实时改城市库存，顶栏从城市聚合展示，而 faction 聚合并未同步。

**证据**：`12-officer-sunjian-biography.png`（与 `05`、`07` 对比）。

### 明显异常 A-2：不满足结盟门槛时按钮与终审仍可提交

**复现**

董卓友好 -65 时，“结盟”按钮可用并显示“结盟率 26%”；点击后终审允许确认；确认后服务端才报
“友好不足（需≥30）”，弹窗继续停留。

**影响**

玩家被引导进入一个必败的提交流程；成功率展示与实际门禁冲突。

**定位**

- `client/src/components/layout/LeftPanel.tsx:270-279`：按钮仅在 loading/已同盟时禁用，未纳入
  战争与 `fav < 30`；
- `server/src/engine/diplomacy.ts:194-215`：服务端正确执行友好≥30与非战争校验。

**证据**：`18-alliance-low-favor-confirm.png`、`19-alliance-result.png`。

### 明显异常 A-3：战役阵型下拉把 ID 6 错标为“冲阵”

出征阵型显示“锋矢/方阵/鹤翼/鱼鳞/冲阵”，其中“冲阵”提交值为 6；项目数据中的冲阵为 ID 16，
ID 6 是锋矢阵。此问题与 Session 178 已记录的遗留一致，当前真实流程仍可复现。

**定位**：`client/src/components/campaign/CampaignPanel.tsx` 内硬编码阵型选项，未使用共享
`FORMATION_LABEL`。

**证据**：`13-campaign-compose.png`。

### 明显异常 A-4：密探任务结束后无可选特工，派出按钮仍显示可用

洛阳探秘失败后，密探进入“休整·冷2”，特工选择框只剩“选择特工…”，但“派出（探秘）”按钮
仍为 enabled，目标洛阳仍被保留。虽然本轮未再次确认提交，以免无意义污染流程，但可用态与当前草稿
明显不一致。

**涉及**：`client/src/components/layout/SpyPanel.tsx` 的任务草稿复位与禁用条件。

**证据**：任务完成后的页面状态（`22-spy-mission-confirm.png` 前后文字记录）。

### 体验瑕疵 U-1：失败错误跨面板残留

结盟被拒后，切换到谍报面板，顶栏仍持续显示“友好不足”；直到下一次成功动作才消失。
错误没有归属感，容易让玩家误以为新操作失败。

**涉及**：`client/src/stores/gameStore.ts` 的全局 `error` 生命周期及各面板切换。

### 体验瑕疵 U-2：主要历史人物孙坚列传为空

孙策与孙坚四页签技术上均正常，但孙坚“列传”显示“暂无列传记载”。对 190 历史剧本的推荐展示人物
而言内容缺失明显，不过不阻断玩法。

**证据**：`12-officer-sunjian-biography.png`。

### 体验瑕疵 U-3：君主折叠仍保留第二个“结束回合”入口

顶栏已有“结束回合”，君主面板另有“结束回合收获+AI”。本轮按明确范围不修，仅再次确认
Session 190 审查记录的问题仍存在。

**证据**：`32-court-gated.png`。

## 四、未发现异常的部分

- 所有已执行的内政、搜索、出征调拨、进贡、谍报、计谋成本都正确扣除，未出现负数；
- 人口/粮耗信息非空，回合后人口与收支按日志稳定变化；
- 高风险操作的终审窗在出征、进贡、结盟、密探招募/任务、离间计中都能正常弹出；
- 孙策、孙坚的四页签均能切换，未见白屏；
- 历史事件能阻止带待决事件推进，并可完成多段叙事与分支选择；
- 除 Army 重复 key 外，未捕获未处理异常、网络错误或后端崩溃。

## 五、建议修复顺序

1. **先修 B-1 + B-2，作为同一个战役完整性补丁**：同节点敌我判定接外交关系；战后更新必须先按
   攻守双方 ID 去重替换，并增加 GameState Army ID 唯一性断言。
2. 增加“190 孙坚/曹操同盟同时抵达洛阳”的确定性回归，覆盖不交战、不复制 Army。
3. 修 A-2 的结盟前端门禁；终审成功率只能在所有硬门槛通过后显示。
4. 统一 faction 资源聚合实时同步或让君主简册直接从城市派生。
5. 顺手收敛 A-3/A-4 与错误生命周期，最后补人物列传内容。

在 B-1/B-2 修复并重新跑通“孙坚出征洛阳 → 与盟军共存/共同攻董 → 正常围城或占领”以前，
**190《关东义兵》完整展示性流程不应标记为通过**。
