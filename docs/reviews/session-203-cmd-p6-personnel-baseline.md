> 范围：S20 / S11 / S12 既有人事入口的迁移前审计。本文只记录当前行为与后续信息架构，
> 不新增入口、不改变规则、不迁移运行时 JSX。
>

## 一、结论与边界

现有唯一生产入口是左栏“人事”手风琴，依次纵向堆叠名册、搜索与登用、任命、美女资源。
权威状态均来自 Zustand `game` 快照，写操作经既有 store action 调既有 `/api/game` 端点；
组件只保存查询、排序、当前对象、轨道、官职和终审开关等客户端草稿。

后续抽屉固定分面为：

```text
名册｜招贤｜任官｜赏罚
```

- **名册**：己方武将列表、姓名筛选、排序、人物简册。
- **招贤**：搜索与在野男将登用。
- **任官**：文官、地方、武官、霸府四轨任命/解职。
- **赏罚**：本批仅承接已实装的美女库存赏赐。“罚”、没收、俘虏录用均未实装，不造假按钮。
- **调动**：当前没有独立调动引擎/API；仅记录为“设计中”，不出现在可点击导航。

本批不迁移外交献美、内政寻访美女、家族婚配/历史女角、总军师、俘虏处置、军事编成，
也不新增批量调动、功绩等级或 0-B 大名单。旧手风琴在 CMD-P10 原子切换前继续作为唯一入口。

### 2.1 权威、派生与草稿边界

- 权威：`GameState.officers/factions/cities/actionLog` 与服务端 PRNG 状态。
- 派生：名册过滤排序、搜索城回退、任命候选/门槛展示、成功率展示、官职当前标签。
- 草稿：查询词、排序、选中人物、待登用对象、任命轨道/官职/对象、赏赐对象及终审开关。
- 禁止迁移时复制：搜索/登用概率、官职门槛、唯一官职清理、忠诚/资源结算。

## 三、终审与错误基线

每个可提交动作都必须保留以下断言，而不是只保存截图：

| 动作 | 取消断言 | 确认后的权威断言 | 错误状态断言 |
|---|---|---|---|
| 搜索 | 城金与日志不变 | 执行城金−80，首条日志 `personnel_search` | 终审打开后耗尽城金，再确认显示“城中金钱不足”，且不提交 |
| 登用 | 有候选时目标势力/状态与日志不变 | `verify-personnel-rng` 断言支付城金−200、`personnel_recruit` 日志及成功/失败权威 PRNG 结果 | 当前两个 0-A 初始局均无 `FREE` 武将；Headless 必须明确断言“暂无在野武将”且提交按钮为0，不伪造候选 |
| 文/地/武/霸府任命 | 四轨现职与日志不变 | 首条日志 `appoint`，目标对应轨道等于选择值 | 终审打开后由权威 API 先完成同一任命，再提交显示服务端“已是该…职” |
| 美女库存赏赐 | 库存、忠诚与日志不变 | 库存−1，忠诚按上限100增加12，首条日志 `beauty_reward` | 终审打开后耗尽库存，再确认显示“美女库存不足”且不提交 |

`scripts/verify-cmd-p6-headless.mjs` 使用 1440×900 Chrome，缺应存在的入口或断言对象时直接抛错，
不得条件跳过。它同时断言左栏可从名册顶部滚到美女资源底部、终审取消/确认、上述错误可见，
以及控制台错误为 0。登用是唯一无法在当前初始局形成提交按钮的操作；浏览器基线断言真实空状态，
提交结算由 `pnpm verify-personnel-rng` 的确定性成功/失败断言补齐，不能声称浏览器点过不存在的候选。

## 四、重复入口与跨域依赖

### 4.1 搜索重复入口

- 人事“搜索人才”是 S11 人才搜索，唯一写入口为 `/personnel/search`。
- 内政“寻访”是 S09 美女库存获取，唯一写入口为 `/civil/seek-beauty`。
- 名册输入框“检索姓名”纯客户端过滤，不消耗资源。

三者中文近似但语义不同。迁移时“招贤”必须写清人才搜索；“赏罚”只展示美女库存去向，
不能把内政寻访复制进人事。

### 4.2 朝廷官制跳转

当前 `command-court-open-personnel` 通过 `commandNavigation` 打开旧“人事”手风琴，目标语义是：
**打开人事域并定位“任官”，默认关注霸府轨道**。CMD-P9 应把这个导航意图改指正式人事抽屉；
不得在朝廷抽屉复制 `AppointPanel`、候选或提交逻辑。

### 4.3 人物简册入口

名册点击行或“名将试册”头像的目标语义是：**以 officer id 打开唯一 `OfficerDetail` 人物简册，
关闭后返回原名册查询/排序/滚动上下文**。未来人物简册中的人事快捷动作只发送
“打开人事域 + 分面 + officer id”导航意图，不内嵌第二份任命/赏赐表单。

## 五、CMD-P7～P10 保留边界
