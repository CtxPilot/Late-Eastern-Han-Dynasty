### 4.3 唯一计算顺序（契约，沿用 FM 计划 §5.2）

```text
F_raw = formations.json 阵型 Lv1 modifiers + 阵型地形项 + bestUnits 项 + 阵型特殊项
F_effective = F_raw >= 0 ? F_raw × organizationExecution : F_raw   # 负修正原值保留
T_base = 战术自身基础修正                                          # 不受组织度缩放
resolvedDelta = (F_effective + T_base) × synergy                    # 1.1 / 0.9 / 1.0
```

> 负阵型修正必须原值保留（崩散清零正面收益，但不消除圆阵攻击弱点/锥形防御弱点）；
> 组织度五档只缩放**正面阵型增量**，不放大负面；暴击/反击/连击最终概率仍由既有 `crit.ts` 结算。
